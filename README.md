# ريناد | RENAD — منصة معرض فساتين الأعراس

منصة رقمية متكاملة لمعرض متخصص بفساتين الأعراس: استعراض التشكيلة، مشاهدة الفستان بزاوية **360°** تفاعلية، حجز موعد تجربة، وطلب الشراء أو الإيجار — مع لوحة تحكم كاملة لإدارة كل المحتوى.

**الشعار:** إطلالتكِ التي تحلمين بها تبدأ من ريناد ✨

---

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 18 + TypeScript + Vite |
| التنسيق | Tailwind CSS (عربي RTL بالكامل) |
| المسارات | React Router v6 |
| الأيقونات | Lucide Icons |
| قاعدة البيانات | Supabase (PostgreSQL + RLS) |
| الملفات | Supabase Storage (4 Buckets) |
| المصادقة | Supabase Auth |
| النشر | Vercel |

## التشغيل محليًا

```bash
npm install
cp .env.example .env   # ثم املأ المتغيرات
npm run dev
```

### متغيرات البيئة

```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_SITE_URL=https://your-domain.com
```

> لا توجد أي Secrets داخل الكود — المفتاح المجهول (anon key) آمن للاستخدام في الواجهة لأن حماية البيانات تعتمد على سياسات RLS في قاعدة البيانات.

## لوحة التحكم

- الرابط: `/admin`
- الدخول محمي بصلاحية `admin` في جدول `profiles` + سياسات RLS
- إدارة الفساتين (رفع صور + إطارات 360° بترتيب تلقائي حسب اسم الملف)
- إدارة المواعيد: تقويم شهري/أسبوعي/يومي + تأكيد/رفض/تعديل/إلغاء + واتساب
- إدارة المحتوى: الهيرو، النصوص، التواصل، أوقات العمل، صور المعرض — بدون كود
- إشعارات فورية داخل اللوحة عند كل طلب حجز جديد

## بنية قاعدة البيانات

```
profiles (customers / admins)
categories, dresses, dress_images, dress_360_frames
favorites, appointments, business_settings, notifications
```

Storage buckets: `dress-images` · `dress-360` · `hero-images` · `gallery-images`

كل الجداول محمية بـ Row Level Security:

- الزائر: قراءة الفساتين والتصنيفات والإعدادات + إنشاء حجز
- العميلة: مفضلتها وحجوزاتها وإشعاراتها فقط
- المدير: إدارة كاملة عبر دالة `is_admin()`

مكافحة الإساءة: مشغّل يمنع التواريخ الماضية ويحدد 5 طلبات/هاتف/24 ساعة.

## الميزات الرئيسية

- 🖼️ عارض 360° مخصص: سحب بالإصبع/الماوس، قصور حركي، تحميل تدريجي Lazy، تكبير ووضع كامل
- 🎛️ نظام عرض مرن لكل فستان: صور فقط / 360° فقط / الاثنين بتبويبات
- 🔍 بحث وتصفية متقدمة (كود، تصنيف، مقاس، لون، سعر، إيجار/شراء، متوفر الآن) — متزامنة مع الرابط
- 📅 نظام حجز يقرأ أوقات العمل والتواريخ المغلقة من لوحة التحكم
- ♥ مفضلة محلية للزائرة ومتزامنة مع الحساب عند تسجيل الدخول
- 💬 زر واتساب برسالة جاهزة تذكر كود الفستان — الرقم قابل للتعديل من اللوحة
- ⚡ أداء: Code Splitting، تحميل تدريجي للصور، Skeletons، صور WebP، CDN
- 🔎 SEO: عناوين ووصف ديناميكي، Open Graph، JSON-LD للمنتجات، sitemap.xml، robots.txt

## النشر

```bash
npm run build        # يولّد dist/ + sitemap.xml
npx vercel --prod    # أو اربط مستودع GitHub بمشروع Vercel
```

أضف متغيرات البيئة الثلاثة أعلاه في إعدادات المشروع على Vercel.

## سكربتات الصيانة

```bash
# تطبيق ملفات SQL على قاعدة البيانات
node scripts/db.mjs --token=<SBP_TOKEN> --ref=<PROJECT_REF> supabase/migrations/001_schema.sql

# البيانات الأولية (صور + فساتين + إطارات 360)
node scripts/seed.mjs --token=<SBP_TOKEN> --ref=<REF> --anon=<ANON_KEY>
```
